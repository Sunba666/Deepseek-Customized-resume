# ADR-0001: Web 优先，Tauri 最后

- 状态：已接受
- 日期：2026-08-14

## 背景

产品定位为「本地运行的桌面端求职辅助软件」，PRD 预设 Tauri 2.0 桌面壳。但开发机当前未安装 Rust 工具链（cargo/rustc 均缺失），Tauri 要求 Rust + MSVC 构建链 + WebView2，安装与首次编译成本高。

## 决策

开发阶段以 **Web 优先**：同一套 React + FastAPI 前后端在浏览器中开发与验证；功能全部完成后，最后再引入 Tauri 2.0 薄壳打包成桌面应用（src-tauri 骨架先预留）。

## 后果

- 优点：不阻塞开发；前后端与 Tauri 解耦，桌面壳只是「本地服务器 + WebView」的封装；后续任何平台都可复用。
- 代价：打包发布阶段需要安装 Rust 工具链；桌面壳整合（端口管理、生命周期）是收尾阶段的一次性工作。
- 前端始终通过相对路径调用后端 API（开发时 Vite proxy，打包后 Tauri 拉起本地服务）。
