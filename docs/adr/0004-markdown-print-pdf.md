# ADR-0004: 导出用 Markdown + 浏览器打印生成 PDF

- 状态：已接受
- 日期：2026-08-14

## 背景

PRD 要求导出 Markdown 或 PDF 格式的求职方案。Windows 上常见的 Python PDF 方案差异大：weasyprint 依赖 GTK 运行库（安装步骤多、易踩坑），reportlab/fpdf2 纯手写排版样式朴素。

## 决策

- 后端生成 **Markdown** 报告（确定性内容，含全部公司/风险/渠道/建议）。
- PDF 由**前端调用浏览器打印对话框（window.print）** 另存为 PDF，报告页以打印样式排版。
- 导出前一律经过脱敏（手机号/邮箱/身份证/住址等）。

## 后果

- 优点：零额外系统依赖，安装简单；排版质量即浏览器渲染质量，支持中文。
- 代价：PDF 不是后端直接产物，需用户手动「另存为 PDF」；浏览器打印样式需单独维护（`print:` Tailwind 变体）。
- 若未来需要后端直出 PDF，可切换到 weasyprint 而无需改动报告数据模型。
