# ADR-0002: 复用本地公司库 + mock 回退

- 状态：已接受
- 日期：2026-08-14

## 背景

PRD 要求公司推荐与风险核验有数据源，同时规定「开源仓库不得包含任何真实公司数据，使用模拟数据」。开发机已有 `E:\自己制作的项目\Company-lookup` 项目，内含 `company_data.db`（48 家公司 + 企业信用缓存）与 `company_knowledge.db`（500+ 家知识库种子企业），其中信用缓存含 AI 风险报告（tavily / wenshu / salary 数据源）。

## 决策

- **本地库优先**：运行时优先读取 Company-lookup 的 SQLite 数据库作为本地公司库与风险数据源（通过 `COMPANY_DB_PATH` 配置路径）。
- **mock 回退**：本地库查不到的公司/风险数据，回退到内置模拟数据。
- **仓库纯净**：真实数据库文件通过 `.gitignore` 排除，不进入仓库；提交到 GitHub 的只有模拟数据生成器。

## 后果

- 优点：无 API Key 时推荐与风险核验仍有真实感；仓库符合 PRD 开源约束；后续接入企查查/天眼查 API 只需替换 `risk_checker` 的数据源实现。
- 代价：依赖另一项目的数据库文件路径，需在 `.env` 中配置；Company-lookup 的库结构变化时需同步适配。
- 风险数据一律带「数据获取时间」与来源标注；无数据时标注「未知」，禁止编造。
